## 1. Chrome extension (review this first)

**Where:** `extension/` · **Install:** `chrome://extensions` → Developer mode →
Load unpacked → pick `extension/`. **No publishing needed.**

The popup gives you:

- **Quick task / note / log** — one line, Enter. Log mode adds a category and
  duration.
- **Tab group → task link.** "Working on" assigns the group you're in to a
  task. A task captured inside a group auto-links to it. A group belongs to at
  most one task, so linking elsewhere releases the old owner.
- **Pomodoro** — live countdown, minutes-left badge, and **start / pause /
  skip** controls.
- **Accent-themed icon** — the toolbar icon is the Ligand bolt, redrawn in
  whatever accent the app is using.

**Architecture — deliberately no backend.** The extension never writes Ligand's
storage. Its content script relays to the page and the *page* performs every
write through the real store actions (`src/hooks/useExtensionBridge.js`). One
data model, works in guest mode with no sign-in, rides existing Supabase sync
when signed in. Captures made while Ligand is closed queue and flush when a
Ligand tab loads.

**Security:** messages are rejected unless they come from the page's own window
and origin — verified by an injection attempt from an iframe, which was
correctly ignored. Tasks marked private from assistants are withheld from
snapshots. No browsing history is collected; no URLs are sent to Ligand.

⚠️ If your live Ligand is on a custom domain (not `*.vercel.app`), add it to
`host_permissions` **and** `content_scripts.matches` in `manifest.json`.

## 2. Pomodoro kept running when you leave its tab — this was a real bug

You asked whether the Pomodoro still rings if you switch to Journal. It did
not, and it was worse than that.

**Reproduced before the fix:** start a 3-second block, switch to Journal, wait.
`focusLog` stayed **empty** and the session was stuck claiming `running: true`
with an end time already in the past. The tab is lazily mounted, so leaving it
tore down the interval *and* the phase-end effect — **your focus time was
silently lost**, and nothing chimed.

**After:** the same run logs the block, advances to the break, and rings
(verified: 1 focus-log entry, phase `short`, 25 audio oscillators while sitting
on Journal).

The engine now lives at app level in `src/hooks/usePomodoroEngine.js`; the tab
is a pure view over it. The website blocker's focus flag is derived from the
engine too, so it's correct on every tab.

## 3. Journal voice notes and clips

- **Voice note** — tap to start, tap to stop.
- **Quick clip** — press *and hold*, release to stop (the QuickTake gesture).

**On music:** the clip records with the **mic off**, which is what lets your
music keep playing. A voice note must take the mic, so iOS pauses playback —
there is no web API to request "mix with others", so the UI says so up front
rather than surprising you.

**Storage:** blobs go to **IndexedDB**, not into the entry. Photos ride the
record as base64 inside `ligand.data`, which syncs *whole* on every change —
fine for images, fatal for media given Safari's ~5 MB localStorage cap.
Recordings cap at 15s video / 2min audio. Codecs are chosen by walking a
support ladder (Safari records MP4, Chrome records WebM), unit-tested against
both.

**Cloud sync (phase 3):** recordings upload to a private Supabase Storage
bucket and any signed-in device can fetch and cache them. Local-first is
preserved — IndexedDB is written first, upload is best-effort, and a sweep on
sign-in pushes anything captured offline.

⚠️ **Action needed:** apply `supabase/migrations/202607270001_journal_media_storage.sql`
to your Supabase project. Until then, everything silently falls back to
device-local — no breakage, just no sync.

## 4. Smaller fixes

- **Task scheduling** — a "When" row with one-tap **Today / Tomorrow** chips
  plus a date field. Tasks scheduled for a date now show up in that day's
  Today's focus; the Day planner's place-list is scoped to the viewed date.
- **Goal details are editable** — the widget claimed "you can adjust this
  later" but was read-only. Now has full edit (SMART fields + target date) on
  every goal.
- **"Days showing up since \<install date\>"** on a new goal — that was a
  legacy auto-seeded count-up shown on every goal dashboard. The old cleanup
  was gated by a one-shot flag that could run before cloud data hydrated and
  miss it; now idempotent.
- **Sounds actually work.** The AudioContext unlock was gated behind the
  UI-sounds toggle, but the Pomodoro chime deliberately *bypasses* that toggle
  — so with sounds off the context stayed suspended and the chime was silent.
- **Repeating completion chime** — 3 rings when you're looking at the app, or
  until you return when you aren't (capped), stopping on focus or any click.
- **Pause nudge** — a gentle chime when a pause runs past its planned length.
- **Timer survives refresh** — running sessions resume from an absolute end
  time, paused ones restore frozen, and the pause stopwatch persists.
- **Mute dot** — a 22px circle under the avatar at 0.22 opacity. Mutes UI
  sound effects **only**; timer chimes and alarms are unaffected.
- **Focus picker no longer jumps** — it was centred with `translateX(-50%)` but
  the open animation re-animated `transform` without that offset. Now fades
  opacity only.
- **Log focus you already did** — for time put in before starting the timer.

## Known limitations / open items

1. **The Supabase migration above must be applied** for recording sync.
2. **Electron themed icon is untested on a real desktop build.** The wiring is
   in (`desktop:accent-icon` IPC → `mainWindow.setIcon` + tray), and the
   renderer-side drawing is verified, but I could not run the packaged app from
   here. macOS ignores `setIcon` for the Dock — it uses the bundle icon — so
   there the tray updates but the Dock will not.
3. **iOS recording needs real-device testing.** Standalone-PWA camera/mic has
   historically been flaky; I can't verify iOS from here.
4. Recordings are not inside the JSON export (both Settings screens say so).
