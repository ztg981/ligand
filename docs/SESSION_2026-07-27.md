## 1. Chrome extension

**Install:** `chrome://extensions` → Developer mode → **Load unpacked** →
select `extension/`. Pin it. **No publishing needed.**

Open Ligand in a tab; the popup header should say **connected**.

- **Quick task / note / log** — one line, Enter.
- **Tab group → task.** "Working on" assigns the group you're in to a task.
  A task captured inside a group auto-links to it.
- **Pomodoro** — live countdown, **start/pause/skip**, minutes-left badge.
- **Icon wears your accent** — change Ligand's theme, the toolbar icon follows.

Captures made while Ligand is closed queue and flush when a tab opens.

*No backend:* the extension never writes storage itself; the page performs
every write through the real store actions. Works in guest mode, no sign-in.

⚠️ If your live Ligand is on a custom domain (not `*.vercel.app`), add it to
`host_permissions` **and** `content_scripts.matches` in `manifest.json`.

## 2. Pomodoro — a real bug, worth testing

**Start a block, switch to Journal, wait for it to end.**

It used to lose the session entirely: the tab is lazily mounted, so leaving it
tore down the clock *and* the phase-end handler. Nothing chimed and **the focus
time was never logged**. Now it rings and logs wherever you are.

Also: **End session** banks the minutes already spent (unlike Reset, which
discards them), with a receipt. Focus tracking was verified end-to-end from
both routes — ending early, and letting a block finish.

## 3. Journal recordings

Composer → **Record** opens a camera-style sheet: Voice/Video, live preview,
big shutter, timer.

- **Hold to record; slide right to lock** (15s → 3 min when locked).
- **Back camera and sound are the defaults.** An early version recorded video
  silently — a clip of someone talking was worthless. Mute is now an explicit
  toggle for when you want music to keep playing.
- Blobs live in IndexedDB, not the entry (Safari's ~5 MB localStorage cap makes
  base64 media impossible); syncs to Supabase Storage once the migration is in.

## 4. Journal map

An interactive map of where entries were written, with bubbles that re-cluster
as you zoom, plus entries placed / distinct places / where you write most.

Uses Leaflet + OpenStreetMap — Apple and Google both need an external SDK that
this app's `script-src 'self'` policy blocks outright. Lazy-loaded, so you only
pay the 150 KB if you open it.

**Entries written before this have no coordinates and won't appear.** Make a new
entry with location to see it work.

## Known limitations

- Recordings aren't in the JSON export (both Settings screens say so).
- **iOS needs real-device testing**: silent-switch behaviour, recording in a
  standalone PWA, and whether the hold/slide gesture feels right.
- Safari re-asks for camera permission per page load. **Add Ligand to your Home
  Screen** — installed PWAs persist the grant.
- Music resuming after a recording is iOS's call; we release the audio session
  promptly, which is the most the web allows.
- macOS ignores `setIcon` for the Dock, so there only the tray follows the theme.
